### 2.1 认证

| 件 | 值 | 来源 |
|---|---|---|
| Cookie | 同源，`credentials: include` | 全部项目 |
| H5 头 | `xtbz: ykt`、`X-Client: h5` | helper 系 |
| Web 头 | `university-id`、`uv-id`、`X-Client: web`、`Xt-Agent: web` | helper 系 |
| Bearer | 任意响应头 `Set-Auth`，回写后放 `Authorization: Bearer …` | Yuketang-JS、yuketangHelperBUU |

本项目的做法：`net.ts` 统一在每次响应里读 `set-auth`，命中就更新 `YtClient.bearer`，
并持久化到 `state.json` 的 `cache.ytBearer`，重启不用先进课堂也能续上。

### 2.2 WebSocket

地址 `wss://<host>/wsapp/`，握手：

```json
{"op":"hello","userid":"<identityId>","role":"student","auth":"<lessonToken>","lessonid":"<lessonId>"}
```

服务端 op（本项目 `ws.ts` 全部处理）：

| op | 方向 | 本项目用途 |
|---|---|---|
| `hello` | R | 连接确认 |
| `unlockproblem` | R | 触发取题 + 按策略作答 |
| `extendtime` | R | 延时提醒 |
| `probleminfo` / `problemfinished` | S/R | 状态刷新 / 收题 |
| `fetchtimeline` | S/R | 事件流；也是 45s 保活包 |
| `showpresentation` / `presentationcreated` | R | 拿 presentationId 并预取题目 |
| `slidenav` | R | 翻页 |
| `lessonfinished` | R | 下课 |
| `callpaused` | R | 随机点名（含姓名学号） |
| 其它 | — | 记 `protocol` 事件（未知 op 计数 = 改版预警） |

### 3.1 登录加密

```
AES-128-CBC，key = iv = "u2oh6Vu^HWe4_AES"，PKCS7，输出 base64
uname    = base64(AES(phone))
password = base64(AES(password))
```

单测里用 **Python `cryptography` 独立算出的向量**做交叉验证（`tests/protocol.test.mjs`：
`AES('13800138000') === 'yYcVatS+4J+JGnm88UM56A=='`），避免"自己验自己"。

### 3.2 签到字段

```
activeId, address, latitude, longitude, fid=0, appType=15, ifTiJiao=1, [code]
```

- 位置签到：**教师指定坐标优先**，没有才用设置里的默认坐标（`settings.chaoxing.location`）。
- `code`：手势图案 / 签到码，来自 `getPPTActiveInfo.signcode`。
- 二维码：`otherInfo` 里带 `enc`，十秒一变 → 只提醒，不自动。
- 返回值：文本 `success` 视为成功，其它一律记失败原因。

### 3.3 活动类型

| activeType | 含义 | 处理 |
|---|---|---|
| 0 / 2 / 74 | 签到 | `status === 1`（进行中）时按白名单处理 |
| 47 | 作业 | 只统计进作业表 |
| 其它 | 讨论/测验/直播 | 只展示 |

## 4. 本项目额外做的事（参考项目里没有的）

1. **桌面端持久登录**：用 Electron `persist:` 分区装 cookie，`session.fetch` 发请求，
   登录窗口与协议层共享同一份会话 —— 扩展/脚本方案都要在页面上下文里搬 token，这里不需要。
2. **事件去重**：`dedupeEvents()` 把 3 分钟内同 `(platform, kind, title, detail)` 的事件合并，
   否则每次启动都会多一条"未登录"。
3. **未登录探测节流**：未登录时每 10 轮才打一次探测请求，避免每 20s 一条 401 刷日志。
4. **协议漂移计数**：未知 WS op 单独计 kind=`protocol`，事件流页有"未知 op 次数"面板。
5. **统一事件流**：两个平台的事件进同一条时间线，便于对照（例如"雨课堂下课 + 学习通签到"）。
6. **纯函数抽离**：`core/pure.ts` 与 `platforms/yuketang/normalize.ts` 不 import electron，
   所以 Node 原生 type-stripping 能直接跑单测。
